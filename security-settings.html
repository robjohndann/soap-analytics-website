How this works

When two-step verification is ON, everyone who signs in to this school needs a code from an authenticator app. People without one are asked to set one up at their next sign-in.

Changing this setting needs a code you entered in the last 5 minutes, from an authenticator that was set up before you signed in. Every change is recorded, and turning it OFF needs a reason.

Only this school’s Headteacher, a Multi-School Leader assigned to it, or a SOAP Analytics administrator can change it.
